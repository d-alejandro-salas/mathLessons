Módulo 0 Fundamentos Teóricos y Propiedades Operatorias

Función Exponencial

Estructura general con corrimientos horizontales y verticales:

\( f(x) = A \cdot b^{x - h} + k \quad (b > 0, \, b \neq 1) \)
  • Dominio: Siempre \(\text{Dom}(f) = \mathbb{R}\).
  • Asíntota Horizontal (AH): Recta \(y = k\).
  • Imagen: Si \(A > 0 \implies \text{Im}(f) = (k, +\infty)\); si \(A < 0 \implies \text{Im}(f) = (-\infty, k)\).
  • Crecimiento: Creciente si (\(b > 1\) y \(A > 0\)) o (\(0 < b < 1\) y \(A < 0\)).

Definición y Propiedades de Logaritmos

\( \log_b(a) = c \iff b^c = a \quad (a > 0, \, b > 0, \, b \neq 1) \)
1. \(\log_a(a) = 1; \log_a(1) = 0\) 2. \(\log_a(u \cdot v) = \log_a u + \log_a v\) 3. \(\log_a(u/v) = \log_a u - \log_a v\) 4. \(\log_a(u^n) = n \cdot \log_a u\) 5. Cambio de base: \(\log_b a = \frac{\log a}{\log b} = \frac{\ln a}{\ln b}\)

Función Logarítmica: Presenta Asíntota Vertical en la frontera de su argumento (\(x - h = 0 \implies x = h\)).

  1. #25 Problema Adicional 1

    Análisis con Base Neperiana (\(e\))

    Determina analíticamente el dominio, imagen, asíntota horizontal y la función inversa de \( g(x) = e^{x-1} - 2 \).

    Ver Solución Paso a Paso

    • \(\text{Dom}(g) = \mathbb{R}\)

    • \(\text{Im}(g) = (-2, +\infty)\)

    • Asíntota Horizontal: \(y = -2\)

    • Despeje: \(x = e^{y-1} - 2 \implies x+2 = e^{y-1} \implies \ln(x+2) = y - 1\)

    • Inversa: \(g^{-1}(x) = \ln(x+2) + 1\)

  2. #26 Problema Adicional 2

    Ecuación con Propiedad de Producto

    Resuelve para \(x \in \mathbb{R}\): \( \log_2(x) + \log_2(x-2) = 3 \).

    Ver Solución Paso a Paso

    • Restricción de dominio: \(x > 0 \land x-2 > 0 \implies x > 2\)

    • Producto: \(\log_2(x(x-2)) = 3 \implies x^2 - 2x = 2^3 = 8\)

    • Cuadrática: \(x^2 - 2x - 8 = 0 \implies (x-4)(x+2) = 0\)

    • Descarte: \(x = -2\) no pertenece al dominio del logaritmo.

    • Solución única: \(x = 4\)
